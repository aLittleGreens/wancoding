# Docker 零基础7天学习计划

> 本学习计划适合没有任何Docker基础的同学，按天循序渐进，帮助你快速入门并掌握Docker的核心用法。

---

## 第1天：认识Docker与安装

**学习目标：**
- 了解什么是Docker，为什么要用Docker。
- 理解容器与虚拟机的区别。
- 完成Docker的安装。

**学习内容说明：**
- 阅读官方文档或推荐教程，了解Docker的基本概念。
- 了解Docker的应用场景。
- 按照操作系统（Windows/Mac/Linux）安装Docker Desktop。

**课后练习：**
1. 用自己的话总结Docker的定义和优势。
2. 列举3个你认为Docker适合的应用场景。
3. 截图你的Docker安装成功界面。

**学习效果分析建议：**
- 能否清楚表达Docker与虚拟机的区别？
- 是否能独立完成Docker的安装？
- 总结是否有自己的理解？

---

## 第2天：Docker的基本命令

**学习目标：**
- 掌握常用的Docker命令。
- 能够运行第一个容器。

**学习内容说明：**
- 学习docker version、docker info、docker run、docker ps、docker stop、docker rm等命令。
- 运行hello-world镜像，体验容器启动。

**课后练习：**
1. 运行hello-world镜像并截图。
2. 用命令行查看当前运行的容器。
3. 尝试停止并删除一个容器。

**学习效果分析建议：**
- 是否能独立使用命令行操作容器？
- 是否理解每个命令的作用？

---

## 第3天：镜像管理

**学习目标：**
- 理解镜像的概念。
- 学会查找、下载、删除镜像。

**学习内容说明：**
- 学习docker images、docker pull、docker rmi等命令。
- 了解Docker Hub。

**课后练习：**
1. 搜索并下载nginx镜像。
2. 查看本地所有镜像。
3. 删除一个不用的镜像。

**学习效果分析建议：**
- 是否能熟练管理本地镜像？
- 是否理解镜像和容器的关系？

---

## 第4天：容器操作进阶

**学习目标：**
- 掌握容器的端口映射、数据卷挂载。
- 能够让容器与主机、其他容器通信。

**学习内容说明：**
- 学习docker run -p、-v参数。
- 了解容器网络模式。

**课后练习：**
1. 运行nginx容器并映射端口到主机。
2. 挂载一个本地目录到容器。
3. 用浏览器访问nginx服务。

**学习效果分析建议：**
- 是否能让容器服务在主机访问？
- 是否理解数据卷的作用？

---

## 第5天：自定义镜像与Dockerfile

**学习目标：**
- 理解Dockerfile的作用。
- 能够编写简单的Dockerfile并构建镜像。

**学习内容说明：**
- 学习Dockerfile的基本指令（FROM、RUN、COPY、CMD等）。
- 编写一个简单的Dockerfile。

**课后练习：**
1. 编写Dockerfile构建一个自定义nginx镜像。
2. 运行自定义镜像并验证效果。

**学习效果分析建议：**
- 是否能独立编写Dockerfile？
- 是否理解镜像构建流程？

---

## 第6天：Docker Compose与多容器应用

**学习目标：**
- 了解Docker Compose的作用。
- 能够编写docker-compose.yml文件。

**学习内容说明：**
- 学习Compose的基本语法。
- 编写一个包含nginx和redis的docker-compose.yml。

**课后练习：**
1. 用Compose启动nginx+redis。
2. 修改配置让nginx和redis能互通。

**学习效果分析建议：**
- 是否能独立编写和运行Compose文件？
- 是否理解多容器编排的意义？

---

## 第7天：常见问题与实战演练

**学习目标：**
- 掌握排查常见问题的方法。
- 综合运用前6天所学。

**学习内容说明：**
- 总结常见报错及解决办法。
- 设计一个小型实战项目（如本地部署个人博客）。

**课后练习：**
1. 选择一个开源项目，用Docker部署并运行。
2. 记录遇到的问题和解决过程。

**学习效果分析建议：**
- 是否能独立查阅文档解决问题？
- 是否能将所学知识应用到实际项目？

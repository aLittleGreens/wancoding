# 一、模仿URL的文章内容进行仿写
可以通过 `@Url` 的方式投喂模板文章，也可以通过在对话框中粘贴内容的方式投喂模板文章。

# 二、通过@Web让Cursor生成文章时去检索更多的信息
@Web 请帮我生成一篇介绍deepseek的文章，要求能清晰的描述出deepseek算法为什么比gpt有优势，为什么会带来成本上的降低。

# 三、将常用的名人名言作为外挂知识库

## 1. 可以让Cursor给我们提供一些名人名言
请给我一些常用的关于心理学的名人名言，并将其生成到文件：`心理学名人名言.txt`

## 2. 从文件中选择合适的名人名言
帮我写一段300字左右，关于7岁孩子性格养成和教育中应该注意事项的短文。

要求：
- 为了有理有据，要从 `@心理学名人名言.txt` 文件中选择合适的名人名言填充到文章中，并辅以对应的案例故事。
- 名人名言不要用的过多，只选择1-2个既可。

# 四、利用Composer能够生成文件和修改文件的能力

## 1. 规划目录
我想写一个关于6岁儿童教育的一系列文章，预计有10篇文章左右，请你帮我规划该系列文章的目录。

## 2. 生成文件
### 2.1 normal模式
请你根据刚才提供的内容帮我生成对应的文章。

### 2.2 agent模式（可以一次性生成多个文件）
`@6岁儿童教育系列文章目录.txt` 请你使用agent能力帮我生成全部的文章，一次性都生成，可以么？

## 3. 补充文章内容
请帮我补充文章内容，要求内容有理有据，最好辅以看起来非常真实的案例加以说明。
